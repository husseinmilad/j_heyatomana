# نسخه ویندوز

نسخه دسکتاپ با Electron ساخته می‌شود و همان رابط React نسخه وب را اجرا می‌کند.

## ساخت Setup.exe در ویندوز

```bash
npm install
npm run dist:win
```

خروجی نصب‌کننده در پوشه `release/` قرار می‌گیرد.

## محل نگهداری داده‌ها

اطلاعات برنامه به‌صورت JSON در فایل `database.json` در پوشه اختصاصی داده‌های کاربر Electron (مسیر userData ویندوز) نگهداری می‌شود. این پوشه مستقل از محل نصب است؛ بنابراین به‌روزرسانی یا نصب مجدد برنامه نباید فایل داده را حذف کند.

## نسخه وب

فرمان `npm run build` و گردش‌کار GitHub Pages بدون تغییر باقی می‌مانند. نسخه دسکتاپ با فرمان جداگانه `npm run build:desktop` ساخته می‌شود که از مسیرهای نسبی برای بارگذاری فایل‌های محلی استفاده می‌کند.
